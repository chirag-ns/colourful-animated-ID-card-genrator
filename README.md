# Hacker House Goa 2026 - Boarding Pass Generator

A colourful, animated ID card (boarding pass) generator for Hacker House Goa 2026. Built by **Chirag N S**.

**🚀 Live Demo:** [https://hhgoa-boardingpass.vercel.app/](https://hhgoa-boardingpass.vercel.app/)

## Features

- **Interactive UI**: Engaging, animated landing page featuring a tropical Goan theme.
- **Customizable Passes**: Upload your photo, enter your name, designation/stack, and city.
- **Live Preview & Controls**: Adjust the zoom and position of your photo in real-time on the boarding pass.
- **Export & Share**: Download your generated pass or instantly share it to 𝕏 (Twitter).

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- [Vite](https://vitejs.dev/) - Frontend Tooling
- [qrcode](https://www.npmjs.com/package/qrcode) - QR Code generation
- [heic2any](https://www.npmjs.com/package/heic2any) - HEIC image support

## Getting Started

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/chirag-ns/colourful-animated-ID-card-genrator.git
   ```
2. Navigate into the project directory:
   ```bash
   cd colourful-animated-ID-card-genrator
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## Deployment

The project is pre-configured for deployment on platforms like Vercel (via `vercel.json`) or Netlify (via `netlify.toml`). You can simply import this repository into your preferred platform to get a live URL.
